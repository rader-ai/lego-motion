# Brick Studio

A starter kit for an AI brick studio as a Claude Code plugin: turn any idea into brick-built art boards first, then scenes and short films, built from real brick parts in code and rendered in Blender, tuned toward the craft of the best brick-built features and brick stop-motion films. Claude agents are the crew.

Sister project: [rader-ai/clay-motion](https://github.com/rader-ai/clay-motion). Brick Studio shares its operating model (roles, gates, tracker, critic panel) and lists only what's different.

**Status: v0.1 (design).** No code yet. This repo holds the design docs, the research, and the prompt that has Claude Code build the rest.

**Fan project.** Personal and non-commercial. Not sponsored, authorized or endorsed by the LEGO Group. Brick parts come from the LDraw Parts Library (ldraw.org), CC BY 2.0. See `studio/FAN_RULES.md`.

## Start here

1. Read `KICKOFF_PROMPT.md` (setup steps for Chris at the top).
2. Open Claude Code on Opus 5.5 in this repo, with `clay-motion` cloned next to it, and paste the prompt.
